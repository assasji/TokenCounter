# TokenBar

TokenBar는 macOS 메뉴 막대에서 Claude, Codex, Gemini 계정의 **남은 사용량(%)**을 보여 주는 앱입니다. 설정에서 사용할 서비스를 선택하고 각 서비스의 로그인 버튼으로 연결합니다. Codex는 CLI 설치 없이 ChatGPT 계정으로 로그인할 수 있습니다.

> 현재는 소스에서 실행하는 개발 버전입니다. 일반 사용자용 `.app`을 배포하려면 아래의 [공개 배포 전 확인](#공개-배포-전-확인)도 완료해야 합니다.

## 무엇이 표시되나요?

- 메뉴 막대: 각 서비스 아이콘과 가장 짧은 사용량 창의 잔여율
- 아이콘 클릭: 5시간·주간 등 계정이 제공하는 모든 사용량 창, 리셋 시각, 마지막 성공 시각
- 색상: 20% 미만 빨강, 20~50% 노랑, 50% 초과 기본색
- 경고 표시(`⚠`): 새 조회가 실패해 마지막으로 확인된 값을 보여 주는 상태
- `N/A`: 아직 성공적으로 읽은 값이 없는 상태

표시되는 값은 토큰 개수나 돈이 아니라 각 서비스가 반환한 **사용량 창의 남은 비율**입니다. 공급자와 요금제에 따라 창의 종류가 다를 수 있습니다.

## 무료 사용자도 쓸 수 있나요?

가능합니다. TokenBar 자체에는 유료 기능이 없습니다. 다만 아래 두 조건이 필요합니다.

1. 확인하려는 서비스를 TokenBar에 연결해야 합니다.
2. 그 계정에 대해 공급자 서버가 사용량 창을 반환해야 합니다.

무료·유료 여부만으로 표시 가능 여부가 정해지지는 않습니다. 예를 들어 한 서비스만 로그인했다면 그 서비스는 표시되고, 나머지는 `N/A`여도 정상입니다. 계정 종류에 사용량 창이 없거나 공급자가 응답 형식을 바꾸면 해당 서비스만 표시되지 않을 수 있습니다.

## 처음 사용하는 방법

### 1. 준비물

- macOS 13 Ventura 이상
- Xcode 15 이상 또는 Xcode Command Line Tools(설치: `xcode-select --install`)
- Swift 5.9 이상
- 확인하려는 공급자의 계정

빌드 도구는 소스에서 직접 실행할 때만 필요합니다. 패키징된 앱 사용자는 터미널이나 Codex CLI를 설치할 필요가 없습니다. 보고 싶은 서비스만 설정에서 켜세요.

### 2. 앱 실행 후 계정 연결

#### Claude Code

메뉴바 Claude 아이콘 → **Claude 로그인…**(또는 설정의 **claude.ai 로그인…**)을 누르면 앱 안의 작은 창에서 claude.ai 로그인이 진행됩니다. 로그인 성공 시 창이 자동으로 닫히고 사용량이 갱신됩니다. CLI·Keychain·파일에 접근하지 않고 이 로그인에서 받은 토큰만 사용합니다. 공개 배포 전 공급자 정책 검토가 필요합니다.

#### GPT / Codex

1. 메뉴바의 ChatGPT 아이콘 → **ChatGPT 로그인…**, 또는 설정의 **Codex (ChatGPT 계정)** → **ChatGPT 로그인…**을 누릅니다.
2. **앱 안에 작은 로그인 창이 열리고** 그 안에서 공식 인증 페이지가 표시됩니다. 외부 브라우저를 열지 않습니다. "Continue with Google/Apple/Microsoft"를 누르면 해당 소셜 로그인도 별도의 작은 팝업 창으로 뜹니다.
3. 계정 선택·동의·추가 인증이 필요할 수 있습니다.
4. 인증이 완료되면 로컬 콜백을 통해 로그인 창이 자동으로 닫히고 사용량이 갱신됩니다. 아이콘 클릭 시 서버가 제공한 5시간·주간 창을 볼 수 있습니다. 사용량 100%는 잔여 0%이며 정상입니다.
5. 계정을 바꾸려면 **다시 로그인…**, 연결을 지우려면 설정에서 **로그아웃**을 누릅니다. 로그아웃은 TokenBar의 로컬 인증만 지우며 ChatGPT 웹에서 로그아웃하거나 서버 토큰을 철회하지는 않습니다.

Codex CLI·보조 바이너리·`~/.codex/auth.json`은 사용하지 않습니다. 표시되는 값은 Codex 사용 한도이며 일반 ChatGPT 웹 대화 전체의 잔여 토큰 수가 아닙니다.

로컬 콜백은 `http://localhost:1455/auth/callback`이며 `127.0.0.1`에만 수신합니다. 포트가 사용 중이면 다른 Codex 로그인 창을 종료하고 다시 시도하세요. 다른 프로세스를 강제 종료하거나 임의 포트로 우회하지 않습니다. 3분 안에 완료하지 않으면 다시 로그인해야 합니다.

로그인을 취소하려면 로그인 창을 닫으면 됩니다.

#### Gemini

메뉴바 Gemini 아이콘 → **Gemini 로그인…**(또는 설정의 **Google 계정 로그인…**)을 누르면 앱 안의 작은 창에서 Google 로그인이 진행됩니다. CLI·Keychain·파일 폴백은 사용하지 않으며 이 로그인에서 받은 토큰만 저장합니다. 공개 배포 전 공급자 정책 검토가 필요합니다.

### 3. TokenBar 실행

저장소 폴더에서 다음 명령을 실행합니다.

```sh
swift build
swift test
swift run TokenBar
```

터미널을 닫거나 `Control-C`를 누르면 앱도 종료됩니다. 메뉴 막대의 각 아이콘을 클릭하면 자세한 사용량을 볼 수 있고, **설정…**에서 자동 갱신 주기를 2·5·15·30·60분 중 선택할 수 있습니다.

### 4. Finder에서 여는 로컬 앱 만들기

```sh
./scripts/build_app.sh
open dist/TokenBar.app
```

`dist/TokenBar.app`이 생성됩니다. 기본값은 로컬 시험용 ad-hoc 서명이며 다른 사람에게 배포하기 위한 서명·공증은 아닙니다. Developer ID 인증서가 있다면 다음처럼 서명 ID를 지정할 수 있습니다.

```sh
TOKENBAR_CODESIGN_IDENTITY="Developer ID Application: 이름 (TEAMID)" ./scripts/build_app.sh
```

공개 릴리스 파일은 서명 후에도 반드시 Apple 공증과 실제 기기 검증을 거쳐야 합니다.

## 자격 증명과 개인정보

로그인은 각 공급자의 공식 인증 페이지에서 진행되며, **앱 안의 작은 창(WebKit)** 으로 표시됩니다. 외부 브라우저를 열거나 시스템 브라우저의 쿠키·프로필을 읽지 않습니다. 로그인 성공 시 access/refresh 토큰, 계정 ID, 만료 시각, 이메일을 앱의 UserDefaults에 저장합니다. **UserDefaults는 암호화 저장소가 아닙니다.** 같은 macOS 사용자 권한을 가진 프로그램이나 환경설정 백업에서 읽을 수 있으므로 공개 배포 전 저장 방식의 보안 검토가 필요합니다. Keychain을 사용하지 않는 것은 보안을 강화하는 조치가 아니라 비밀번호 팝업을 피하기 위한 선택입니다.

| 공급자 | 로컬에서 읽는 위치 | 통신 대상 | TokenBar의 쓰기 동작 |
|---|---|---|---|
| Claude | 앱의 UserDefaults | Claude 인증·사용량 서버 | 자체 OAuth 구현에서 토큰 저장·갱신 |
| GPT / Codex | 앱의 UserDefaults (`openai_oauth_credentials`) | `auth.openai.com`, `chatgpt.com`; 소셜 로그인 시 해당 로그인 제공자 | 최초·갱신 토큰 저장, 로그아웃 시 삭제. CLI 파일·Keychain 접근 없음 |
| Gemini | 앱의 UserDefaults | Google 인증·사용량 서버 | 자체 OAuth 구현에서 토큰 저장·갱신. CLI·Keychain·파일 폴백 없음 |

- 토큰 값, Authorization 헤더, 서버 응답 본문을 로그로 출력하지 않습니다.
- UserDefaults에는 인증 정보와 사용량 캐시가 포함됩니다. 앱 환경설정 파일을 공유하거나 저장소에 넣지 마세요.
- 분석 도구, 광고 SDK, 자체 중계 서버, 외부 패키지 의존성이 없습니다.
- 자격 증명을 GitHub 이슈, 화면 캡처, 로그에 올리지 마세요.

### 토큰 만료

- Codex는 만료 60초 전 자동 갱신하고, 사용량 조회가 401이면 갱신 후 한 번만 재시도합니다. 새 refresh 토큰도 저장해 앱 재시작 후 사용합니다. 동시에 여러 조회가 들어와도 토큰 갱신은 한 번만 수행합니다.
- 인증이 거절되면 다시 로그인하세요. 일시적인 네트워크·서버 장애만으로는 로그인 정보를 삭제하지 않습니다.
- Claude·Gemini도 별도 OAuth 관리자가 갱신을 담당합니다.

## 오류 해결

### 한 서비스만 `N/A`인 경우

설정에서 해당 서비스가 켜져 있고 로그인되어 있는지 확인하세요. Codex는 **ChatGPT 로그인…**으로 연결합니다. 로그인 후에도 `N/A`이면 오류를 확인하세요. 제공되지 않은 창이나 알 수 없는 값을 임의로 0%·100%로 만들지 않습니다.

### `%⚠`가 보이는 경우

퍼센트는 마지막 성공 값입니다. 네트워크를 확인하거나 앱의 해당 서비스에서 재로그인하세요. Codex 로그아웃·계정 변경 시 이전 계정의 캐시는 비웁니다.

### Keychain 접근 창을 거절한 경우

Codex의 새 로그인·조회 경로는 Keychain을 사용하지 않으므로 이 창을 띄우지 않습니다. 계속 뜬다면 다른 공급자의 기존 폴백이나 실행 중인 이전 TokenBar 버전인지 확인하세요. 이번 변경은 Gemini·Claude의 인증 코드를 수정하지 않습니다.

### 값을 잘못 표시하는 것 같은 경우

각 CLI가 자체 화면에서 보여 주는 사용량과 먼저 비교하세요. 계정 식별 정보나 토큰을 제거한 응답 구조와 재현 절차만 이슈에 첨부해 주세요.

## 개발

```sh
swift build
swift test
```

구성은 작게 유지합니다.

- `Models.swift`: 공급자, 사용량 창, 오류 모델
- `Services.swift`: 공급자별 인증 관리자 연결·사용량 조회·응답 파싱
- `OpenAILogin.swift`: Codex OAuth, PKCE/state, Chrome 우선 인증 페이지 열기, 루프백, 토큰 저장·갱신
- `MonitorStore.swift`: 병렬 조회, 일정 갱신, 민감정보 없는 캐시
- `TokenBarApp.swift`: 메뉴 막대 UI
- `PreferencesView.swift`: 서비스 선택·계정 연결·갱신 주기 설정

테스트는 mock 네트워크 응답과 임시 자격 증명 파일만 사용합니다. 실제 사용자 계정이나 실서버에 접속하지 않습니다.

Codex의 새 테스트는 메모리 환경설정·가짜 토큰과 mock 응답만 사용합니다. 잘못된 콜백/state, PKCE, 토큰 회전, 동시 갱신, 루프백 타임아웃을 검사합니다. 실제 소셜 로그인·계정별 사용량 확인은 사용자가 직접 로그인하는 별도 수동 검증입니다.

### Codex 인증 규격 확인 근거

- [OpenAI 인증 문서](https://learn.chatgpt.com/docs/auth): 브라우저 로그인과 기본 콜백 포트 1455.
- 로컬 Codex `0.154.0` 바이너리의 `login/src/server.rs` 관련 문자열: `/oauth/authorize`, `/auth/callback`, PKCE·scope·추가 authorize 플래그, `grant_type=authorization_code&code=…&redirect_uri=…&client_id=…&code_verifier=…` form 본문.
- `ServerOptions::new` 디스어셈블리의 기본 포트 상수 `0x5af`(1455), JWT의 `https://api.openai.com/auth` → `chatgpt_account_id` 필드.
- authorization code 교환은 form, refresh는 JSON. `id_token` 원문은 저장하지 않고 필요한 계정 메타데이터만 추출합니다.

현재는 Codex 클라이언트 규격을 재현한 호환 구현입니다. TokenBar 자체 OAuth 클라이언트 등록이나 OpenAI의 제품 승인·공식 지원을 의미하지 않습니다. CLI와 동일한 scope에는 connector 권한도 포함되므로 최소 권한·배포 적합성은 별도로 검토해야 합니다.

## 중요한 제한사항

TokenBar는 세 공급자의 공식 제품이 아니며 제휴·승인을 의미하지 않습니다. Claude, ChatGPT, Codex, Gemini와 각 로고는 해당 소유자의 상표입니다. 특히 [OpenAI 로고 사용 지침](https://openai.com/brand/)에 따라 로고는 OpenAI 관련 기능을 식별하는 용도로만 사용해야 합니다.

현재 사용량 조회 경로는 각 CLI가 사용하는 로그인과 백엔드 동작을 바탕으로 한 **비공개·비보장 통합**입니다. 공개적으로 안정성이 보장된 사용량 API가 아니므로 공급자의 정책, 인증, 경로 또는 응답 형식 변경으로 예고 없이 중단될 수 있습니다. 이 앱을 결제·과금 판단의 유일한 근거로 사용하지 마세요.

## 공개 배포 전 확인

GitHub에 소스를 공개하는 것과 일반 사용자에게 안전한 `.app`을 배포하는 것은 별도 단계입니다.

- 저장소 라이선스 선택 및 `LICENSE` 추가(법적 선택이므로 저장소 소유자가 결정)
- 앱 고유 bundle identifier와 버전 정책 결정
- Apple Developer ID로 서명하고 Apple 공증(notarization) 수행
- Apple Silicon과 Intel에서 각각 실행 확인 또는 Universal Binary 생성·검증
- 각 공급자의 이용약관과 상표·로고 사용 권한 최종 확인
- GitHub의 비공개 보안 취약점 신고 기능 활성화
- 공급자 백엔드 변경에 대응할 유지보수 정책 명시

서명·공증되지 않은 앱을 일반 사용자에게 배포하면 Gatekeeper 경고가 발생합니다. 개발 인증서와 배포 인증서는 저장소에 올리지 마세요.
