# TokenCounter

🌐 **English**: [README.en.md](README.en.md)

TokenCounter는 macOS **메뉴 막대(화면 맨 위 줄)** 에서 Claude · ChatGPT(Codex) · Gemini 계정의 **남은 사용량(%)** 을 보여 주는 작은 앱입니다. 각 서비스의 로그인 버튼만 누르면 되고, 평소 사용에 터미널이나 CLI 설치는 필요 없습니다.

---

> ## ⚠️ 먼저 읽어주세요 — 중요 경고
>
> TokenCounter는 **비공식(unofficial) 도구**입니다. Anthropic(Claude), OpenAI(ChatGPT), Google(Gemini)과 **아무런 제휴·후원 관계가 없습니다.**
>
> 사용량을 가져오기 위해 각 서비스의 **공식 문서에 없는 내부 API**를 호출합니다. 이 방식은 각 공급자의 **이용약관(ToS)에 어긋날 소지가 있으며**, 그 결과로:
>
> - 로그인/조회가 어느 날 갑자기 막히거나,
> - **당신의 계정이 제한·정지될 수 있습니다.** (특히 Claude는 유사한 서드파티 도구를 실제로 차단한 전례가 있습니다.)
>
> **모든 사용은 전적으로 본인 책임(use at your own risk)입니다.** 이 위험을 이해하고 감수할 수 있을 때만 사용하세요. 걱정된다면 설정에서 **자동 조회 주기를 길게(예: 15분 이상)** 두는 것을 권장합니다.

---

## 무엇이 보이나요?

- **메뉴 막대**: 각 서비스 아이콘 + 가장 짧은 사용량 창의 잔여율(예: `43%`)
- **아이콘 클릭**: 5시간·주간 등 계정이 제공하는 모든 사용량 창과 리셋 시각
- **색상**: 20% 미만 빨강 / 20~50% 노랑 / 그 이상 기본색
- `⚠`: 로그인이 필요하거나 최근 조회가 실패한 상태
- `N/A`: 아직 성공적으로 읽은 값이 없는 상태

표시되는 값은 토큰 개수나 요금이 아니라, 각 서비스가 알려주는 **사용량 창의 남은 비율**입니다.

## 설치 방법 (macOS · 단계별)

> 지금은 **소스 코드로 배포**됩니다. 아래 단계대로 하면 됩니다. 한 번만 설정해두면 다음부터는 바로 실행됩니다.
> (Apple 서명이 없는 앱이라 처음 열 때 macOS가 한 번 물어봅니다 — 6단계 참고.)

### 1단계. 개발 도구 설치 (최초 1회, 약 5분)

`터미널`(응용 프로그램 → 유틸리티 → 터미널)을 열고 아래를 붙여넣고 Enter:

```sh
xcode-select --install
```

창이 뜨면 **설치**를 누릅니다. 이미 설치돼 있으면 "이미 설치됨"이라고 나오는데 그대로 넘어가면 됩니다.

> 필요 조건: **macOS 13 (Ventura) 이상**.

### 2단계. 코드 내려받기

**쉬운 방법 (Git 몰라도 됨):**
1. 이 GitHub 페이지에서 초록색 **`Code`** 버튼 → **`Download ZIP`** 클릭
2. 다운로드된 ZIP을 더블클릭해 압축 해제 (보통 `다운로드/TokenCounter-main` 폴더가 생김)

**Git을 쓸 줄 안다면:**
```sh
git clone https://github.com/assasji/TokenCounter.git
```

### 3단계. 그 폴더로 이동

터미널에서 `cd ` (뒤에 공백 하나) 까지 친 뒤, **압축 푼 폴더를 터미널 창으로 드래그**하고 Enter. 예:

```sh
cd ~/Downloads/TokenCounter-main
```

### 4단계. 앱 만들기 (빌드)

```sh
./scripts/build_app.sh
```

처음엔 1~2분 걸릴 수 있습니다. 끝나면 그 폴더 안 `dist/TokenCounter.app`이 만들어집니다.

### 5단계. 응용 프로그램에 넣기

```sh
mv dist/TokenCounter.app /Applications/
```

(또는 Finder에서 `dist` 폴더를 열어 `TokenCounter.app`을 `응용 프로그램`으로 끌어다 놓기)

### 6단계. 첫 실행 (중요)

Apple 서명이 없는 앱이라 그냥 더블클릭하면 "확인되지 않은 개발자" 경고가 뜹니다. **처음 한 번만** 이렇게 여세요:

- `응용 프로그램`에서 **TokenCounter 아이콘을 우클릭(또는 Control+클릭) → 열기 → 열기**

한 번 이렇게 열면 그다음부터는 평소처럼 더블클릭으로 실행됩니다. 실행되면 화면 맨 위 **메뉴 막대**에 아이콘이 나타납니다(독(Dock)에는 안 뜹니다).

## 로그인 (계정 연결)

메뉴 막대 아이콘을 클릭하거나 **설정…**을 열어, 보고 싶은 서비스의 로그인 버튼을 누릅니다.

- **Claude**: 메뉴의 **Claude 로그인…** → 앱 안의 작은 창에서 claude.ai 로그인
- **ChatGPT / Codex**: **ChatGPT 로그인…** → 작은 창에서 로그인 ("Continue with Google" 등도 지원)
- **Gemini**: **Gemini 로그인…** → 작은 창에서 Google 로그인

로그인은 모두 **앱 안의 작은 창**에서 진행되며, 성공하면 창이 자동으로 닫히고 사용량이 표시됩니다. 로그아웃/계정 변경은 **설정…**에서 할 수 있습니다.

> **팁**: 설정에서 **자동 갱신 주기**를 2·5·15·30·60분 중 고를 수 있습니다. 위 경고에서 설명한 이유로 **15분 이상**을 권장합니다.

## 종료 · 다시 실행

TokenCounter는 메뉴 막대 앱이라 Dock에 아이콘이 없고, 창을 닫아도 종료되지 않습니다.

- **종료하기**: 메뉴 막대 아이콘 클릭 → 맨 아래 **TokenCounter 종료** (단축키 `⌘Q`). 그러면 메뉴 막대에서 아이콘이 사라집니다.
- **다시 실행하기**: 아래 중 편한 방법
  - **Spotlight**: `⌘Space` → `TokenCounter` 입력 → Enter
  - **Finder**: `응용 프로그램` 폴더에서 `TokenCounter` 더블클릭
  - **Launchpad**: Launchpad를 열고 `TokenCounter` 클릭
  - (소스에서 실행 중이라면) 터미널에서 `swift run TokenCounter`
- **로그인해서 Mac 켤 때 자동 실행되게 하려면**: `시스템 설정 → 일반 → 로그인 항목`에서 `+`를 눌러 `TokenCounter`를 추가하세요.

## 개인정보 · 보안

- TokenCounter는 **별도의 서버가 없습니다.** 각 공급자에게 **직접** 요청하며, 어떤 데이터도 제3자에게 보내지 않습니다.
- 로그인은 각 공급자의 공식 인증 페이지에서 진행되며 **앱 안의 작은 창(WebKit)** 으로 표시됩니다. 시스템 브라우저의 쿠키·프로필을 읽지 않습니다.
- 로그인 성공 시 access/refresh 토큰·계정 ID·만료 시각·이메일을 앱의 **UserDefaults**에 저장합니다.
  **⚠️ UserDefaults는 암호화 저장소가 아닙니다.** 같은 Mac 사용자 권한을 가진 프로그램이나 환경설정 백업에서 읽힐 수 있습니다. (Keychain을 쓰지 않는 것은 보안 강화가 아니라 반복되는 비밀번호 팝업을 피하기 위한 선택입니다.)
- 토큰 값·인증 헤더·서버 응답 본문을 로그로 남기지 않습니다.

## 자주 겪는 문제

- **한 서비스만 `N/A`**: 그 서비스에 로그인하지 않았거나, 계정에 해당 사용량 창이 없을 수 있습니다. 로그인만 하면 나머지는 `N/A`여도 정상입니다.
- **`⚠` 표시**: 로그인이 필요하거나 마지막 조회가 실패한 상태입니다. 해당 아이콘의 **다시 로그인…** 또는 **지금 갱신**을 눌러보세요.
- **값이 이상해 보임**: 표시는 각 서버가 준 값 그대로입니다. 사용량 100%는 "잔여 0%"라는 뜻이며 정상입니다.

## 개발자용

```sh
swift build      # 빌드
swift test       # 테스트
swift run TokenCounter   # 소스에서 바로 실행
```

- 외부 런타임 의존성 없음(순수 Swift/SwiftUI/AppKit/WebKit).
- 세 공급자는 각각 독립된 브라우저 OAuth 구현을 사용하며, CLI/파일/Keychain 폴백은 사용하지 않습니다.
